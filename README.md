# gittraining7
 
A personal sandbox for practising Git. It contains a few small text files and a commit history of 16 commits on `main`. There is no application code.
 
## Contents
 
| File | Notes |
|------|-------|
| `mybranch1.txt`, `mybranch2.txt` | Small text files tied to the branch exercises |
| `mycheckfile.txt`, `myfile`, `myfile1` | Scratch files for staging, committing and diffing |
| `.gitignore` | Ignore rules |
 
The history is the useful part of this repo. It includes a `git revert` exercise (noted inside `mybranch1.txt`).
 
## Explore it
 
```bash
git clone https://github.com/agangwar07/gittraining7.git
cd gittraining7
git log --oneline --graph --all
```
 
## Commands to practise here
 
- `git add`, `git commit`, `git status`, `git diff`
- `git branch`, `git switch`, `git merge`
- `git revert` to undo a commit without rewriting history
- `git log` for reading history
## Note
 
The repository is public and only meant for practice. Its contents can be deleted or rewritten at any time.
